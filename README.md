# College Student Placement Analysis

This project explores a college placement dataset and compares several classification models for predicting whether a student is placed.

## Dataset

- `college_student_placement_dataset.csv`

## Notebook

- `college_student_placement_analysis.ipynb`

## Models Tried

- Logistic Regression - 90.35%
- Naive Bayes Classifier - 91%
- SVM Classifier - 97.9%
- Decision Tree - 96.3%
- KNN - 95%
- XGBoost - 99.05%
- Random Forest - 99.95%

## Workflow

1. Load and inspect the dataset.
2. Check for duplicates and missing values.
3. Preprocess categorical features.
4. Train and compare classification models.
5. Evaluate model performance.

## How to Run

Open the notebook in Jupyter or VS Code and run the cells from top to bottom.
